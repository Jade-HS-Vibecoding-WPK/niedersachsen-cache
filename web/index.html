Niedersachsen-Cache

OpenStreetMap-Daten der Großstädte Niedersachsens und Wilhelmshavens, fertig vorbereitet auf GitHub Pages. Apps holen ihre Daten hier in unter einer Sekunde, statt bei Overpass 30–60 Sekunden in der Warteschlange zu warten.

In deiner App benutzen

<script src="https://jade-hs-vibecoding-wpk.github.io/niedersachsen-cache/nds-cache.js"></script>
<script>
  async function ladeOsm(abfrage) {
    const daten = await NdsCache.overpass(abfrage);
    if (daten) return daten;          // aus dem Cache
    return ladeLive(abfrage);         // sonst wie bisher
  }
</script>
